# QMEP Electromechanical LLC — Website

Company website and admin panel for QMEP Electromechanical LLC (HVAC, electrical, plumbing and MEP maintenance in Dubai).

## Development

Requires Node.js 20+ (or Bun).

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Tests

```sh
npm test
```
